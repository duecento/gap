# GAP Ministries

Single-page website for GAP Ministries — a charity shop and foodbank community centre in Moira, Northern Ireland, based at Eden House.

## Stack

- React + TypeScript + Vite
- Tailwind CSS v4
- `motion` for scroll/entrance animations

## Development

```bash
npm install
npm run dev
```

## Photos

Drop real photos into `public/images/` using these filenames and they'll replace the placeholder blocks automatically:

- `logo.png` — GAP Ministries logo
- `facade-1.jpg` … `facade-4.jpg` — Eden House exterior shots
- `shop-1.jpg` … `shop-7.jpg` — charity shop interior shots (used in the Gallery section)
